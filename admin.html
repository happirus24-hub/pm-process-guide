GitHub 연결
링크를 저장하려면 GitHub Personal Access Token이 필요합니다.
토큰은 이 기기의 세션에만 임시 저장되며, 외부로 전송되지 않습니다.
토큰 발급 방법
  1. GitHub → 우측 상단 프로필 → Settings
  2. 왼쪽 메뉴 맨 아래 → Developer settings
  3. Personal access tokens → Tokens (classic)
  4. Generate new token (classic) 클릭
  5. Note: PM Guide Admin / Scope: public_repo 체크
  6. Generate token → 복사하여 위에 붙여넣기
